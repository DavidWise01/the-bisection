THE BISECTION METHOD &mdash; a member of [[methodos]]. Bracket a root where f changes sign (it must cross, by the Intermediate Value Theorem), test the midpoint, keep the half that still straddles zero &mdash; the interval halves each step, one bit per step. Unconditionally convergent given a valid bracket, so it&rsquo;s the safe fallback inside hybrid solvers. &#9670; LIT: a fail-loud check throws unless it brackets x&sup3;&minus;x&minus;2 to 1e&minus;9. &#9650; AMBER: needs a sign-change bracket, converges only linearly.
